# Changelog

## 1.0

- Initial Zabbix 7.0 release.
- Tenancy-wide File System and Mount Target discovery within a configured OCI region.
- OCI File Storage lifecycle and metadata collection.
- FILE_SYSTEM_LEVEL quota monitoring.
- Provider-side throughput, latency, metadata and Mount Target health monitoring.
- Optional private-IP enrichment through OCI Core API.
- API collector health monitoring.
- Raw collector payloads excluded from long-term history.
